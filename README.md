# CROP-NEXUS-AI

### Smart Agricultural Supply Chain Traceability & Market Intelligence Platform

CropNexus AI helps improve agricultural supply chain transparency through:

- QR-based crop batch traceability.
- GPS-based geographical shipment tracking.
- Agricultural market price intelligence.
- Market comparison and net-profit estimation.

## Technology Stack

- Frontend: React.js, Vite
- Backend: Python, FastAPI
- Database: SQLite
- Maps: Leaflet, OpenStreetMap
- Routing: OSRM

## Project Status
